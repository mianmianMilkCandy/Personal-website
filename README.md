# 个人主页 · Personal Website

一个纯静态的个人简历 / 作品集站点：**React 19 + Vite 7 + TypeScript**，无后端、无运行时依赖、无跟踪脚本。

整站是一根 **9 面棱柱的九个侧面** —— 滚动即绕视口水平中轴翻面；九个页面共用同一幅「连续天空」背景：云在飘，一列火车沿地平线巡航，可悬停停车、可按住拖动。

---

## 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 框架 | React 19 + TypeScript 5.9（strict） | 全站组件化，三份 tsconfig（root / app / node） |
| 构建 | Vite 7 | `base: './'`，产物可放任意子目录 / GitHub Pages / 对象存储 |
| 样式 | 原生 CSS + 设计令牌 | 无 CSS 框架、无 CSS-in-JS；视觉参数全部收敛在 `src/styles/tokens.css` |
| 运行时依赖 | 零第三方 | 无 UI 库、无动画库、无图标库；图标全部手写内联 SVG |

工程细节：

- **安全构建**：`npm run build` 走 `scripts/build.mjs` —— 类型检查 → 构建到中间目录 → 全部成功才换入 `dist/`，任何一步失败都不破坏上一版可用产物。
- **安全策略**：构建期注入 meta CSP（`vite.config.ts`），另附 `public/_headers` 补全 HSTS / nosniff / Referrer-Policy 与缓存策略，供支持的托管平台读取。
- **性能纪律**：无常驻 rAF 动画循环；滚动帧内不读布局；翻面的面内不做 `backdrop-filter`；动画只走合成层（opacity / transform），并全量遵循 `prefers-reduced-motion`。
- 全部交互动效（翻面驱动、光标、列车巡航）为手写实现，不引入任何动画库。

## UI 设计

主题方向是「**晴空绘本 × 工程师的仪表盘**」：画面负责"童心"，控件负责"克制与可信"。三条纪律：

1. **表面分级 + 发丝描边**：表面走 `--ink-*` 语义层级，边界一律 `1px` 发丝线；不用大圆角、不用大投影。
2. **单一强调色，只用在微观细节**（状态点、焦点环、激活下划线、hover 微光），不做大面积填色或渐变背景。
3. **玻璃质感只留在不旋转的地方**（固定导航、入场幕屏）—— 面内翻面时禁用模糊，保住帧率。

主要设计元素：

- **九面棱柱舞台**：滚动量 → 绕视口水平中轴的旋转角，相邻两面在视口正中成 90° 棱；每次翻面，面内内容重播一遍进出场动画。
- **连续天空（SkyStage）**：底图 / 云漂移层 / 列车精灵 / 天光四层固定合成。列车沿透视钢轨从右往左巡航，悬停指数减速停车（制动 0.46s / 起步 2.1s），按住可拖动改位。
- **动态光标**：精确小点 + 缓动跟随细环，悬停可点元素时环放大并填一层极淡强调色底；原生光标只在自定义光标就位后才隐藏。
- **入场幕屏**：首次访问者看到「进入网站」幕屏，点击 / 任意键进入；`localStorage` 去重，`prefers-reduced-motion` 下直接跳过。
- **手绘图标系统**：手写内联 SVG 图标集（圆头圆角 + 每枚一处强调色细节），只用于标签类内容，叙事文字保持文字。

## 排版设计

- **PC 优先、整屏构图**：首屏是四角分工的一屏 —— 左上字标 / 右上控件 / 左下大标题 / 右下玻璃卡 / 底边 SCENE 行，中间留白全给画面。
- **一屏一面是硬约束**：每个面的内容必须恰好装进一个视口（超出会被 `overflow: hidden` 静默裁切），排版预算按实测净空数字压缩，不凭肉眼判断。
- **字体分工**：Inter Tight 承担标题与正文；JetBrains Mono 承担全部元数据 —— 编号、标签、数值统一等宽 + 大写 + 字距。
- **令牌驱动**：颜色、字号、间距、动效时序全部写在 `tokens.css`，组件里禁止字面色值，换主题 / 调排版只动这一个文件。
- **可读性分层**：背景从亮云跨到镜面水，对比度由「正文带白纱 + 实白卡片」承担，文字色只需在已足够亮的表面上过 4.5:1。
- **动效排版**：入场阶梯延迟封顶（避免后面的元素"像卡住"），出场统一 320ms 同步退场；标题末尾的句号是全站唯一彩色标点。

## 目录结构

```
├── index.html              入口（内联主题引导脚本 + 背景图预加载）
├── vite.config.ts          base: './'；构建期注入 meta CSP
├── scripts/build.mjs       安全构建：失败不破坏上一版 dist/
├── public/
│   ├── _headers            安全响应头 + 缓存策略（支持的平台生效）
│   └── media/              全部画作素材（天空底图 / 列车精灵 / 头像 / 项目卡）
└── src/
    ├── App.tsx             面表（FACES）：整站 = 棱柱的九个侧面
    ├── components/         Cube 舞台 / SkyStage 连续天空 / 各区块 + 同名 CSS
    ├── data/               profile.ts · projects.ts ← 全部站点内容数据
    ├── hooks/ · lib/       滚动驱动、主题、光标、观察器等小型逻辑
    └── styles/             tokens.css（设计令牌）· base.css · art-scrim.css
```

## 本地运行

```bash
npm install
npm run dev      # 开发预览 → http://localhost:5173
npm run build    # 安全构建 → dist/
npm run preview  # 预览构建产物
```

产物是纯静态的，任意静态服务器可直接托管 `dist/`：

```bash
python -m http.server 5174 --directory dist
```
